Sims 4 族谱查看与导出

把模拟市民 4 存档里的家族关系导出为 GEDCOM（.ged）文件，可以导入 Ahnenblatt、Gramps、MyHeritage 等族谱软件。

点击选择或拖入存档文件（.save） 存档位置：文档\Electronic Arts\The Sims 4\saves\
文件名形如 Slot_00000001.save，在游戏里存档界面可以看到对应的槽位。
文件只在你的浏览器里读取，不会上传到任何地方。

导入 Ahnenblatt

  1. 打开 Ahnenblatt，选择 Datei → Öffnen（文件 → 打开）。英文界面是 File → Open。
  2. 文件类型选 GEDCOM（*.ged），选中下载的文件。
  3. 如果中文名字显示成乱码，在导入设置里把字符集选为 UTF-8。

小人的年龄段、所属家庭和 Sim ID 会写在每个人的备注里。游戏不记录出生和死亡日期，所以去世的小人只标记为“已去世”。

本工具在浏览器本地运行，不收集任何数据。与 EA 和 Maxis 无关。
